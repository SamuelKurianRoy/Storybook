## Root Cause Analysis

The issue was caused by missing `backface-visibility: hidden` on the `.page-side` elements. In 3D CSS transforms:

1. When a `.page` element is flipped with `transform: rotateY(-180deg)`:
   - The `.page-front` (no rotation) ends up facing backward
   - The `.page-back` (`transform: rotateY(180deg)`) ends up facing forward

2. Without `backface-visibility: hidden`:
   - Both elements show their back faces when rotated away
   - Since `.page-front` has `z-index: 2` and `.page-back` has `z-index: 1`
   - The back of `.page-front` rendered on top, blocking the front of `.page-back`

3. With `backface-visibility: hidden`:
   - When rotated away, elements become invisible
   - Only the correctly facing element shows
